# linux-ham-shack
I am putting together a Linux based SDR Ham Radio setup that is, at least for now, built around the Hermes-Lite 2 hardware, Quisk, Carla for mic signal processing, a variety of digital mode packages and some scripting of my own to stitch it all together and keep it working properly. I am currently targeting Linux Mint 22.2 for this project, but will update and branch out as time permits. The goal of this repository is to capture what I have done as a wrapper package that pulls together all of the pieces, installs them and adds what I need to make it all work the way I want it to. This will allow me to install it wherever I want and allow others to replicate my setup, hopefully, with relative ease.

More details will follow as I progress on this project.
